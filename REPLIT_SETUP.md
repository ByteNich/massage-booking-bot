# Инструкция по развертыванию бота на Replit

## Шаг 1: Создание аккаунта на Replit

1. Перейдите на https://replit.com
2. Нажмите **Sign Up** (если нет аккаунта) или **Log In**
3. Можете войти через GitHub, Google или Email

## Шаг 2: Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Придумайте имя бота (например: "Баланс Салон")
   - Придумайте username (например: "balans_massage_bot")
4. **Сохраните токен!** Он будет выглядеть так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

## Шаг 3: Получение Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение или `/start`
3. Бот пришлет ваш ID (например: `123456789`)
4. **Сохраните этот ID** - это будет ваш ADMIN_ID
5. Попросите сотрудника (Наталью) также получить свой ID - это будет EMPLOYEE_IDS

## Шаг 4: Импорт проекта в Replit

### Вариант A: Импорт из GitHub (рекомендуется)

1. На главной странице Replit нажмите **+ Create Repl**
2. Выберите **Import from GitHub**
3. Вставьте URL вашего репозитория:
   ```
   https://github.com/ByteNich/massage-booking-bot
   ```
4. Нажмите **Import from GitHub**
5. Replit автоматически создаст проект

### Вариант B: Создание вручную

1. Нажмите **+ Create Repl**
2. Выберите шаблон **Python**
3. Назовите проект: `massage-booking-bot`
4. Нажмите **Create Repl**
5. Загрузите файлы проекта через интерфейс Replit

## Шаг 5: Настройка переменных окружения (Secrets)

На Replit используется специальная система для хранения секретов:

1. В левой панели найдите иконку **🔒 Secrets** (или Tools → Secrets)
2. Добавьте следующие секреты (нажимая **+ New Secret**):

   | Key | Value | Описание |
   |-----|-------|----------|
   | `BOT_TOKEN` | `ваш_токен_от_botfather` | Токен от @BotFather |
   | `ADMIN_ID` | `ваш_telegram_id` | Ваш Telegram ID |
   | `EMPLOYEE_IDS` | `id_сотрудника` | ID сотрудника (если несколько, через запятую) |

   **Пример:**
   - BOT_TOKEN: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
   - ADMIN_ID: `123456789`
   - EMPLOYEE_IDS: `987654321`

3. Остальные параметры (SALON_NAME, SALON_ADDRESS и т.д.) уже установлены в коде

## Шаг 6: Установка зависимостей

Replit автоматически установит зависимости при первом запуске, но можно сделать это вручную:

1. Откройте **Shell** (вкладка внизу или Tools → Shell)
2. Выполните команду:
   ```bash
   pip install -r requirements.txt
   ```

## Шаг 7: Запуск бота

1. Нажмите большую зеленую кнопку **Run** вверху страницы
2. Бот начнет запускаться
3. В консоли вы увидите:
   ```
   INFO - Database initialized
   INFO - Notification scheduler started
   INFO - Bot started
   ```

## Шаг 8: Тестирование бота

1. Откройте Telegram
2. Найдите вашего бота по username (который указали при создании)
3. Нажмите **Start** или отправьте `/start`
4. Проверьте работу:
   - ✅ Бот отвечает приветствием
   - ✅ Показывает меню (клиент/сотрудник/админ в зависимости от ID)
   - ✅ Можно посмотреть услуги
   - ✅ Можно создать запись

## Шаг 9: Постоянная работа бота (Always On)

⚠️ **Важно:** На бесплатном тарифе Replit бот будет засыпать через некоторое время неактивности.

### Решения:

#### Вариант 1: Replit Hacker Plan ($7/месяц)
- Бот работает 24/7
- Не засыпает
- Больше ресурсов

#### Вариант 2: Использовать UptimeRobot (бесплатно)
1. Регистрируемся на https://uptimerobot.com
2. Создаем Monitor с URL вашего Replit проекта
3. Он будет пинговать ваш бот каждые 5 минут
4. ⚠️ Это не идеально, но помогает

#### Вариант 3: Добавить веб-сервер (для UptimeRobot)
Если нужно, я могу добавить простой веб-сервер в бота для мониторинга.

## Возможные проблемы и решения

### Проблема 1: "ModuleNotFoundError"
**Решение:** Убедитесь, что все зависимости установлены:
```bash
pip install -r requirements.txt
```

### Проблема 2: "BOT_TOKEN is not set"
**Решение:** Проверьте, что вы добавили все Secrets правильно (без пробелов)

### Проблема 3: Бот не отвечает
**Решение:**
- Проверьте, что бот запущен (зеленая точка в консоли)
- Проверьте токен бота
- Посмотрите логи в консоли Replit

### Проблема 4: База данных не создается
**Решение:** Проверьте, что SQLite доступен. Replit поддерживает SQLite из коробки.
