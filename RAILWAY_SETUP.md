# Развертывание бота на Railway.app

Railway - отличная платформа для развертывания Telegram ботов с бесплатными $5 кредитов в месяц.

## Преимущества Railway

- ✅ **$5 бесплатно** каждый месяц (хватает на 24/7 работу бота)
- ✅ **Не засыпает** в отличие от Replit
- ✅ **Автодеплой** из GitHub
- ✅ **Встроенная PostgreSQL** (опционально)
- ✅ **Простая настройка** переменных окружения
- ✅ **Логи** в реальном времени

## Пошаговая инструкция

### Шаг 1: Получите токен бота (2 минуты)

1. Откройте Telegram → найдите **@BotFather**
2. Отправьте `/newbot`
3. Следуйте инструкциям:
   - Имя: `Баланс Салон`
   - Username: `balans_massage_bot` (или любой свободный)
4. **Сохраните токен!** (формат: `1234567890:ABC...`)

### Шаг 2: Получите Telegram ID (1 минута)

1. Откройте **@userinfobot** в Telegram
2. Отправьте `/start`
3. **Сохраните ваш ID** (например: `123456789`) - это ADMIN_ID
4. Попросите Наталью получить её ID - это EMPLOYEE_IDS

### Шаг 3: Создайте аккаунт на Railway (1 минута)

1. Перейдите на https://railway.app
2. Нажмите **Login** → **Login with GitHub**
3. Авторизуйтесь через GitHub
4. Подтвердите email (если попросит)

### Шаг 4: Создайте новый проект (2 минуты)

1. На главной странице Railway нажмите **New Project**
2. Выберите **Deploy from GitHub repo**
3. Если появится запрос - разрешите Railway доступ к GitHub
4. Найдите и выберите репозиторий **massage-booking-bot**
5. Railway автоматически начнет деплой

### Шаг 5: Настройте переменные окружения (2 минуты)

1. В проекте нажмите на сервис (карточка с именем репозитория)
2. Перейдите на вкладку **Variables**
3. Нажмите **+ New Variable** и добавьте:

   | Variable Name | Value | Описание |
   |--------------|-------|----------|
   | `BOT_TOKEN` | `ваш_токен_от_botfather` | Токен от @BotFather |
   | `ADMIN_ID` | `ваш_telegram_id` | Ваш Telegram ID |
   | `EMPLOYEE_IDS` | `id_сотрудника` | ID Натальи (если несколько, через запятую) |

   **Пример:**
   ```
   BOT_TOKEN = 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ADMIN_ID = 123456789
   EMPLOYEE_IDS = 987654321
   ```

4. После добавления переменных Railway автоматически **перезапустит** деплой

### Шаг 6: Проверьте деплой (1 минута)

1. Перейдите на вкладку **Deployments**
2. Дождитесь статуса **SUCCESS** (обычно 1-2 минуты)
3. Нажмите на последний деплой → **View Logs**
4. В логах должно быть:
   ```
   INFO - Database initialized
   INFO - Notification scheduler started
   INFO - Bot started
   ```

### Шаг 7: Протестируйте бота! (2 минуты)

1. Откройте Telegram
2. Найдите вашего бота по username
3. Нажмите **Start** или отправьте `/start`
4. Проверьте работу:
   - ✅ Бот приветствует вас
   - ✅ Показывает меню (администратора для вас)
   - ✅ Можно посмотреть услуги
   - ✅ Можно создать запись

## Дополнительные настройки

### Автодеплой при изменениях

Railway автоматически следит за вашим GitHub репозиторием:
- При каждом push в ветку main/master
- Автоматически перезапускает бота
- Занимает 1-2 минуты

### Использование PostgreSQL вместо SQLite

Если хотите использовать более надежную базу данных:

1. В проекте нажмите **+ New** → **Database** → **Add PostgreSQL**
2. Railway автоматически создаст переменную `DATABASE_URL`
3. Бот автоматически переключится на PostgreSQL
4. Не нужно ничего настраивать - код уже готов! ✅

### Просмотр логов

1. В Railway откройте ваш сервис
2. Перейдите на вкладку **Deployments**
3. Нажмите на активный деплой → **View Logs**
4. Здесь видны все сообщения и ошибки бота в реальном времени

## Управление кредитами

### Сколько стоит работа бота?

На Railway вы получаете **$5 бесплатно каждый месяц**.

Типичный Telegram бот потребляет примерно:
- **$3-4/месяц** при средней нагрузке
- **$5/месяц** хватит с запасом для салона

### Как отслеживать расходы?

1. В Railway перейдите в **Settings** → **Usage**
2. Здесь видно текущее потребление
3. Можно установить лимиты

### Что если кредиты закончатся?

1. Railway приостановит бота
2. Можно привязать карту и платить ~$5/месяц
3. Или оптимизировать использование ресурсов

## Troubleshooting (Решение проблем)

### Проблема 1: Деплой завершился с ошибкой

**Решение:**
1. Проверьте логи деплоя
2. Убедитесь, что все переменные добавлены правильно
3. Проверьте, что репозиторий доступен Railway

### Проблема 2: "BOT_TOKEN is not set"

**Решение:**
1. Проверьте Variables - переменная `BOT_TOKEN` должна быть без кавычек
2. Правильное имя: `BOT_TOKEN` (большими буквами)
3. После изменения Railway автоматически перезапустит бот

### Проблема 3: Бот не отвечает в Telegram

**Решение:**
1. Проверьте логи - там должно быть "Bot started"
2. Проверьте правильность токена
3. Убедитесь, что деплой успешен (статус SUCCESS)
4. Попробуйте перезапустить: Settings → Restart

### Проблема 4: База данных не работает

**Решение:**
1. По умолчанию используется SQLite - работает из коробки
2. Если нужна PostgreSQL - добавьте через "+ New → Database"
3. Проверьте логи на ошибки с БД

### Проблема 5: Бот перезапускается постоянно

**Решение:**
1. Проверьте логи - там будет причина
2. Обычно это ошибка в переменных окружения
3. Проверьте ADMIN_ID и EMPLOYEE_IDS - должны быть числа
