# Telegram Бот для записи на массаж - Салон "Баланс"

Современный Telegram-бот для автоматизации записи клиентов на процедуры массажа в салоне красоты "Баланс".

## Возможности

### Для клиентов
- 📋 Просмотр каталога услуг с ценами и описаниями
- 📅 Запись на процедуры с выбором даты и времени
- 📝 Управление своими записями (просмотр, отмена)
- 🔔 Автоматические напоминания за 24 часа и 3 часа до визита
- 📞 Информация о салоне и контакты

### Для сотрудников
- 📅 Просмотр записей на сегодня
- 📆 Расписание на неделю
- ✅ Отметка выполненных процедур
- 🔔 Уведомления о новых записях и напоминания

### Для администратора
- 👥 Управление сотрудниками (добавление, активация/деактивация)
- 💆 Управление услугами (добавление, редактирование, активация/деактивация)
- 📊 Статистика по записям и доходам
- 📅 Просмотр всех записей с фильтрацией

## Технологии

- **Python 3.10+**
- **python-telegram-bot 20.7** - библиотека для работы с Telegram Bot API
- **SQLAlchemy 2.0** - ORM для работы с базой данных
- **SQLite** - база данных (можно легко заменить на PostgreSQL/MySQL)
- **APScheduler** - планировщик задач для отправки напоминаний

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd massage-booking-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и заполните необходимые параметры:

```env
# Telegram Bot Token (получите у @BotFather)
BOT_TOKEN=your_bot_token_here

# Telegram ID администратора (узнайте у @userinfobot)
ADMIN_ID=your_admin_telegram_id

# Telegram ID сотрудников (через запятую)
EMPLOYEE_IDS=employee_telegram_id_1,employee_telegram_id_2

# Остальные параметры можно оставить по умолчанию
```

### 5. Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

### 6. Получение Telegram ID

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID в `.env` как `ADMIN_ID`
4. Повторите для сотрудников и добавьте в `EMPLOYEE_IDS`

### 7. Запуск бота

```bash
python bot.py
```

## Использование

### Первый запуск

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Бот автоматически:
   - Создаст базу данных
   - Загрузит список услуг
   - Создаст сотрудника "Наталья"
   - Определит вашу роль (администратор/сотрудник/клиент)

### Для клиентов

1. **Просмотр услуг**: Нажмите "📋 Наши услуги"
2. **Запись**: Нажмите "📅 Записаться на процедуру"
   - Выберите категорию услуги
   - Выберите услугу
   - Выберите дату
   - Выберите время
   - Подтвердите запись
3. **Мои записи**: Просмотр и отмена записей

### Для сотрудников

1. **Записи на сегодня**: Просмотр всех записей текущего дня
2. **Расписание**: Просмотр записей на выбранную дату
3. **Отметка выполнения**: Отметка выполненных процедур

### Для администратора

1. **Управление услугами**: Добавление, редактирование, активация/деактивация
2. **Управление сотрудниками**: Добавление, редактирование, активация/деактивация
3. **Статистика**: Просмотр статистики за день/неделю/месяц
4. **Все записи**: Просмотр и управление всеми записями

## Настройка

### Изменение рабочего расписания

Отредактируйте `config.py`:

```python
# Рабочие дни (0=понедельник, 6=воскресенье)
WORK_DAYS = [1, 3, 4, 5]  # вт, чт, пт, сб

# Рабочие часы
WORK_START = 8   # 8:00
WORK_END = 20    # 20:00
```

### Изменение времени напоминаний

Отредактируйте `.env`:

```env
# Напоминания (в часах до записи)
REMINDER_HOURS=24,3
```

### Добавление услуг

Услуги автоматически загружаются при первом запуске из `database/database.py` (функция `add_initial_data`).

Вы также можете добавлять услуги через админ-панель бота.

## База данных

По умолчанию используется SQLite. Для использования PostgreSQL или MySQL:

1. Установите соответствующий драйвер:
   ```bash
   pip install psycopg2-binary  # для PostgreSQL
   # или
   pip install pymysql  # для MySQL
   ```

2. Измените `DATABASE_URL` в `.env`:
   ```env
   # PostgreSQL
   DATABASE_URL=postgresql+asyncpg://user:password@localhost/dbname

   # MySQL
   DATABASE_URL=mysql+aiomysql://user:password@localhost/dbname
   ```

## Деплой

### На VPS (Ubuntu/Debian)

1. Установите необходимые пакеты:
   ```bash
   sudo apt update
   sudo apt install python3-pip python3-venv
   ```

2. Клонируйте репозиторий и установите зависимости (см. раздел "Установка")

3. Создайте systemd service:
   ```bash
   sudo nano /etc/systemd/system/massage-bot.service
   ```

   ```ini
   [Unit]
   Description=Massage Booking Bot
   After=network.target

   [Service]
   Type=simple
   User=your-user
   WorkingDirectory=/path/to/massage-booking-bot
   ExecStart=/path/to/massage-booking-bot/venv/bin/python bot.py
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```

4. Запустите сервис:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable massage-bot
   sudo systemctl start massage-bot
   ```

### На Heroku

1. Создайте `Procfile`:
   ```
   worker: python bot.py
   ```

2. Создайте `runtime.txt`:
   ```
   python-3.10.12
   ```

3. Деплой:
   ```bash
   heroku create your-app-name
   heroku config:set BOT_TOKEN=your_token
   heroku config:set ADMIN_ID=your_id
   git push heroku main
   heroku ps:scale worker=1
   ```
